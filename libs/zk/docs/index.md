# Crypto3.ZK {#zk_index}

Crypto3.ZK provides zero-knowledge proof systems, polynomial commitments,
arithmetization, Fiat-Shamir transcripts, and supporting utilities.

- @subpage zk_introduction describes the implemented protocols and modules.
- @subpage zk_concepts explains the data models shared by those modules.
- @subpage zk_manual shows the current proof and commitment workflows.
- @subpage zk_impl maps the public API to its implementation directories.
- @subpage zk_perf explains how to run the available benchmarks.

For build requirements and a compact module inventory, see the
[library README](../README.md).
